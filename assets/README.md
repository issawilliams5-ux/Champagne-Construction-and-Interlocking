# Assets

## Headshot

Place the official portrait of Bailey Church here as:

```
assets/bailey-church.jpg
```

The site loads this file in the **About** section. Until the file is added,
the page automatically falls back to a neutral stock photo, so it never
shows a broken image. As soon as `bailey-church.jpg` exists in this folder,
the real headshot appears with no further changes needed.

Recommended: a portrait-orientation JPG, at least 900 × 1080px.
